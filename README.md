# NHL Predict

## Descripción

NHL Predict es un sistema desarrollado para la materia de Fundamentos de Bases de Datos.

El proyecto permite consultar información de equipos, standings, partidos, playoffs y generar predicciones de resultados de la NHL utilizando estadísticas históricas.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MySQL

## Funcionalidades

- Consulta de equipos NHL
- Standings por temporada
- Consulta de partidos
- Visualización de playoffs
- Sistema de predicciones
- Base de datos relacional

## Estructura de la base de datos

- Conferencias
- Divisiones
- Arenas
- Equipos
- Temporadas
- Partidos
- Estadísticas de equipo por partido
- Standings
- Playoffs
- Predicciones
